# GACCA Website

Digital platform prototype for the Gainesville Air Conditioning Contractors Association (GACCA).

## Initial goals

- Present GACCA's mission and value to contractors and the community
- Give prospective members a clear path to learn about and join GACCA
- Create a public GACCA Careers hub for member-company job opportunities
- Let member companies submit selected jobs for GACCA review and promotion
- Send applicants directly to the hiring member company's application process
- Build toward events, education, industry resources, member directory, and premium member benefits

## Careers operating model

Member submits a job -> GACCA reviews it -> approved job is published -> GACCA promotes it -> candidate applies directly with the member company.
